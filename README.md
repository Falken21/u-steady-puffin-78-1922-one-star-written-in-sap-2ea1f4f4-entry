A one-line 1-star review written by a houseplant about the human who
bought it. The reviewer is a fern with a paper trail: it was watered
twice in March, then abandoned for a holiday on the strength of a note
to a neighbour that never arrived. The complaint builds like a real
review -- dates, specifics, a failed handover -- and saves its driest
cut for last: the care instructions were in the listing all along, and
the buyer read them. One star, and the star is generous.

## The entry

> ★☆☆☆☆. Watered me twice in March, then went on holiday and left a note for the neighbour that the neighbour never got. I am a fern, not a cactus; the distinction was in the listing he read before buying me.

206 characters.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` with no trailing newline.
